## Part 2 — Code health findings

Rendering core is clean; debt is concentrated in (a) a god-class UI, (b) self-checks that print but never
gate, and (c) half-present/dead systems that blur what's live.

### CRITICAL
1. **Self-checks can't fail CI — every check exits 0 regardless of PASS/FAIL.** `FieldCheck.cs:24-26`,
   `CloudShadowCheck.cs:93-103`, dispatched from `TerrainLabUI.cs`/`Cli.cs`. They compute `bool pass` but only
   `GD.Print` it and `GetTree().Quit()` with no code. → thread `pass` into `GetTree().Quit(pass?0:1)`.
2. **`TerrainLabUI` god-class: ~3,200 LOC, one partial across 16 files, ~8 responsibilities.** CLI parse,
   preset load/persist, sky/celestial/fantasy presets, shot capture, review replay, cloud knobs, randomizer,
   a 429-LOC `_Process`. The central maintainability risk. → extract `CliApplier`/`PresetsManager`/`SkyPresets`/
   `ReviewManager` (LightingComposer already proves the extraction pattern).

### HIGH
3. **Cloud-shadow shader and its self-check compute DIFFERENT math.** `cloud_shadow.glsl:201` applies a
   `smoothstep(0.02,0.5,…)` faint-tail gate; `cloud_shadow_check.glsl:159` doesn't → `--shadowcheck` validates
   math that doesn't ship. (The predicted first divergence of #4.)
4. **Density math triplicated, kept byte-identical BY HAND** across `cloud_raymarch.glsl`/`cloud_shadow.glsl`/
   `cloud_shadow_check.glsl` (`layer_density`/`height_profile`/`density_all`). → extract a shared
   `cloud_density.glsl` `#include`.
5. **Hydrology fully built + self-checked but NEVER instantiated at runtime** — reachable only via
   `--watercheck`. Either wire into `TerrainLab.Build()` or move out of the main tree so it's not mistaken for
   live code. (Ties to the uncommitted restart-#6 files.)
6. **`scripts/workbench/` + `scripts/presenter/` are a dead parallel architecture (~275 LOC).** Only
   `terrain_lab.tscn` is the main scene; Workbench/LabTerrain have zero live callers. → archive/delete.
7. **Chunk-key packing caps the "infinite" world at ~±134M m before silent key collisions.**
   `CdlodTerrain.cs:297-299` packs x/z into 28-bit fields. Fine now, latent infinite-terrain bug. → widen/hash.
8. **`ChunkAabbProvider` syncs a `BufferGetData` readback on the render thread without a fence** (~`:148`) →
   can stall the pipeline. → use the async-collect path.

### MEDIUM
9. **Lake (+1.0 m) vs river (`terrain - bed*0.30`) water levels are inconsistent** — won't meet at confluences
   (moot until #5 is wired). 10. **MFD drainage discards water in pits** (`CoarseDrainage.cs` `cnt==0 continue`) →
   false dry sinks; route to lowest rim. 11. **`--atmoscheck/--aerialcheck/--shadowcheck` print-only, never quit**
   → can't be scripted. 12. **`ObjectListCheck`/`LuminaryPresetCheck` run unconditionally every startup**
   (`TerrainLabUI.cs:66,75`) → gate behind flags. 13. **CLI parse relies on `StartsWith`-vs-exact ORDERING**
   (`--cdlodcheck` before `--cdlod`) → one reorder = silent mis-parse. 14. **Legacy ground path half-present**
   (`--groundv2`/`--gv2debug` declared but never parsed; palette consumed only by shot metadata).
   15. **Double `ToArray()` alloc** in `AtmosphereCompute.cs:~415`.

### LOW / POSITIVE
16. **RID lifecycle + std430 packing are CLEAN** — Texture2Drd assigned once on render thread, freed in
    `_ExitTree`, `Std430Writer` universal. The historical RID-race + packing-drift bug classes are absent.
17. **SSIL-disabled is resolved, not a bug** (thorough root-cause comment in `LightingComposer.cs`).
18. Unused `density`/`cloud_type`/`altitude` scalars in `cloud_shadow.glsl` (trim with #4).
19. Minor off-by-one/clamp smells in hydrology grids (address when #5 reactivates).

**Verification:** one agent "CRITICAL" (a `RiverRibbonMesh.cs:45` UV bug) was discarded as a false positive on
direct read. CDLOD pool + floating-origin snap verified sound.

**Health verdict:** the rendering/sky core can take continued feature work today. But a focused
**consolidation pass** — exit-code the checks (#1), de-dup the cloud density include (#3/#4), extract 2–3
modules from `TerrainLabUI` (#2), and decide hydrology's fate (#5) — should precede the next *large* feature,
or the god-class + non-gating checks keep compounding.
